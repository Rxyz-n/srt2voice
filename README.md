# srt2voice

Turn `.srt` subtitle files into voice-over MP3 tracks using Microsoft Edge's neural text-to-speech.

Each subtitle line is spoken at its exact start time and always finishes before its end time, so the audio stays in sync with the original video and lines never overlap. You get one MP3 per subtitle file, the same length as the subtitle timeline, ready to mix with or replace the original audio track.

## Features

- **Stays on the subtitle timing.** Each line plays only between its own start and end time. Lines too long for their slot are sped up, and if a line is short, the rest of the slot is left silent.
- **More than 300 voices.** Covers every Edge TTS voice and language, with an arrow-key picker you can filter by typing.
- **Fast.** Runs several speech requests in parallel. A 1,000-line file takes a few minutes.
- **Resumable.** If a run is interrupted or fails, the next run reuses the lines already generated.
- **Handles messy files.** Reads non-UTF-8 encodings, missing cue numbers, stray blank lines and music-only lines like `♪` without failing.

## Requirements

- **Python 3.11 or newer**
- **FFmpeg**: `ffmpeg` and `ffprobe` must be on your `PATH`
- **Internet connection**: speech is generated by Microsoft's online Edge TTS service

Install FFmpeg:

```bash
# Ubuntu / Debian / WSL
sudo apt install ffmpeg

# macOS
brew install ffmpeg
```


## Usage

1. Put your `.srt` files in the `subtitles/` folder. It is created on the first run if it doesn't exist yet.
2. Run:

   ```bash
   python main.py
   ```

3. Pick a voice (see below) and press **Enter**.
4. Get your MP3s from `output/`. Each file has the same name as its subtitle file:

   ```
   subtitles/lesson-01.srt  ->  output/lesson-01.mp3
   ```

All `.srt` files in `subtitles/` are processed one after another. If one file fails, the rest still run.

### Choosing a voice

```
Select voice  (Up/Down move | type to filter | Backspace erase | Enter select | Esc quit)
Filter: en-us female
> en-US-AnaNeural                    Female  English (United States)              Cute
  en-US-AriaNeural                   Female  English (United States)              Positive, Confident
  en-US-AvaMultilingualNeural        Female  English (United States)              Expressive, Caring, ...
8/318 voices
```

| Key | Action |
|---|---|
| ↑ / ↓ | Move one line |
| PgUp / PgDn, Home / End | Move by page, jump to the first or last voice |
| Type text | Filter the list |
| Backspace | Remove the last filter character |
| Enter | Select the highlighted voice |
| Esc | Quit |

The list opens with the default voice, `en-US-AriaNeural`, already highlighted, so pressing **Enter** right away keeps it.

When you filter, each word you type must match the start of a word in the voice's name, locale, gender, language or personality. Voices that match a whole word are listed first.

| Filter | Finds |
|---|---|
| `vi` | Vietnamese voices first, then names starting with "Vi" |
| `us male` | US English male voices (does not match "female") |
| `multilingual` | Voices that can speak several languages |
| `ja` | Japanese voices first |

**Choose a voice that matches the language of your subtitles.** An English voice reading Vietnamese text will not produce usable speech.

### Progress output

Each subtitle file gets one progress line, updated in place:

```
[2/5] lesson-02.srt:  64% (640/1000 lines, 12 retries) 01:42
```

When a file finishes, its line is replaced by the result:

```
[1/5] lesson-01.srt: 100% done in 02:41 -> output/lesson-01.mp3 (3 warnings)
    WARNING #4 (line 14): same start time as #3, merged into one line
    WARNING #12: skipped, no speakable text: '♪ ♪'
    WARNING #87: speech cut off (needs 9120ms, slot 80ms)
[2/5] lesson-02.srt: FAILED after 00:00
    Error: Subtitle #7 (line 25): invalid timestamp '00:01:0x,000'
```

| Shown | Meaning |
|---|---|
| `0–99%` | Lines generated and fitted to their time slots |
| `99% merging...` | Placing all lines on the timeline and encoding the MP3 |
| `cached` | Lines reused from an earlier interrupted run |
| `retries` | Speech requests that failed and were retried |
| `100% done` | The MP3 is written |

After the last file, a summary shows the total time and lists any files that failed.

## How it works

For each subtitle file:

1. **Parse.** Read the file (encoding is detected automatically) and collect each cue's start time, end time and text.
2. **Check timing.** Convert timestamps to milliseconds and reject cues that end before they start. Cues that start at the same moment are merged into one.
3. **Compute time slots.** A line may speak from its start until `min(its end, next line's start)`. This is what prevents overlap, even when the subtitle file's own cues overlap.
4. **Generate speech, in parallel:**
   - Edge TTS produces an MP3 for the line, retrying network errors with a backoff.
   - Leading and trailing silence is trimmed.
   - If the speech is longer than its slot, it is sped up to fit. Short speech is never slowed down.
   - The clip is hard-cut at the slot end, with a 20 ms fade so the cut doesn't click.
5. **Merge.** Every clip is pasted at its start time onto a silent timeline, which is encoded once to MP3.
6. **Clean up.** Temporary files are deleted after the MP3 is written.

### Lines that are too long for their time slot

Speech is sped up as much as needed to fit. Above about **2× speed** it starts to sound rushed, and this happens with long sentences on short subtitle durations. If a line sounds too fast, the fix is in the subtitle file: give that cue more time, or shorten its text.

## Folder layout

```
srt2voice/
├── subtitles/       # input: your .srt files
├── output/          # result: one .mp3 per .srt
├── temp/            # working files; deleted after each file succeeds
├── main.py          # entry point and pipeline
├── parser.py        # SRT reading and parsing
├── timing.py        # timestamp checks and same-start merging
├── tts.py           # Edge TTS calls with retry
├── align_audio.py   # silence trim, speed-up and hard cut per line
├── merge_audio.py   # timeline assembly and MP3 encoding
├── progress.py      # progress line
└── voice_picker.py  # interactive voice picker
```

## Configuration

Constants you can change near the top of each module:

| Setting | File | Default | Notes |
|---|---|---|---|
| `TTS_CONCURRENCY` | `main.py` | `8` | Parallel speech requests. Raise it for speed; lower it if you see many retries. |
| `ALIGN_CONCURRENCY` | `main.py` | number of CPU cores | Parallel FFmpeg processes |
| `SUBTITLE_DIR`, `OUTPUT_DIR`, `TEMP_DIR` | `main.py` | `subtitles`, `output`, `temp` | Folder locations |
| `RETRIES`, `RETRY_BASE_DELAY_S` | `tts.py` | `4`, `1.0` | Retries per line; wait time doubles each try (1s, 2s, 4s, 8s) |
| `SILENCE_THRESHOLD` | `align_audio.py` | `-50dB` | Sound quieter than this at the edges of a clip counts as silence |
| `DEFAULT_VOICE` | `voice_picker.py` | `en-US-AriaNeural` | Voice highlighted when the picker opens |

## Subtitle file support

| Input | Handled |
|---|---|
| UTF-8 (with or without BOM), UTF-16, Windows-1252 | ✅ Detected automatically |
| Missing cue numbers | ✅ Numbered by position |
| Blank or whitespace-only lines between or inside cues | ✅ |
| Position data after the timestamp (`X1:100 X2:200 ...`) | ✅ Ignored |
| Short timestamps (`0:00:01,5`) | ✅ Read as 1.5 s |
| Lines with no letters or digits (`♪`, `...`) | ✅ Left silent, with a warning |
| Cues that start at the same time | ✅ Merged, with a warning |
| Overlapping cues | ✅ The earlier line is cut at the next line's start |
| Legacy Vietnamese encodings (VNI, TCVN3) | ❌ Convert to UTF-8 first |

## Troubleshooting

**`No such file or directory: 'ffmpeg'`**
FFmpeg is not installed or not on your `PATH`. See [Requirements](#requirements).

**A file fails because of network errors, or shows many `retries`**
The Edge TTS service is rate-limiting you or the connection is unstable. Lower `TTS_CONCURRENCY` in `main.py` and run again. Lines that were already generated are reused, so the run continues where it stopped.

**`speech cut off` warnings**
The line needed more than 100× speed to fit its time slot, so the end of it was cut. The subtitle cue is far too short for its text; give it more time in the `.srt` file.

**Garbled characters in the speech**
The subtitle file probably uses a legacy encoding. Convert it to UTF-8 with a text editor and run again.

**Interrupting a run**
Press **Ctrl+C**. Lines already generated are kept in `temp/`, and the next run reuses them. If you change a line's text or pick another voice, that line is regenerated automatically.
